# ระบบเวลาและบรรยากาศอยุธยา

เปิด `Scenes/AyutthayaDemo.unity` แล้วกด Play ระบบติดตั้งผ่าน `DemoSceneBootstrap` ทั้งฉากที่สร้างไว้แล้วและฉากที่สร้างตอนเล่น ไม่ต้องสร้างฉากใหม่ทับงานเดิม

## สิ่งที่เพิ่ม

- เวลา 24 ชั่วโมง: 1 วันในเกมใช้เวลา 48 นาทีจริง ปรับ `DayNightCycle.MinutesPerSecond` ได้ (0.5 คือค่าเริ่มต้น)
- แสงเช้า/เย็น ดวงอาทิตย์ ดวงจันทร์ ดาว เมฆเคลื่อนที่ และหมอกสัมพันธ์กับอากาศ
- อากาศแจ่มใส → เมฆครึ้ม → ฝน → ฝนหนัก พร้อมช่วงเปลี่ยน 18 วินาที อากาศสุ่มเปลี่ยนทุก 3–7 นาที ปิดได้ที่ `WeatherManager.AutomaticWeather`
- ฝนตกในพิกัดโลก ติดตามผู้เล่นขณะเดินหรือขับรถ พร้อมเสียงฝนสังเคราะห์
- ผิวถนนเข้มและมันวาวขึ้นเมื่อเปียก แล้วค่อยแห้งหลังฝนหยุด (ไม่ได้เพิ่มแอ่งน้ำหรือระบบสะท้อนภาพแบบ ray tracing)
- โคมไฟถนนเปิดตามความมืด/ฝน มีเสาและส่วนเรืองแสง จำกัดไม่เกิน 32 ดวง และไม่คำนวณเงารายดวง
- ไฟหน้าและไฟท้ายรถเปิดอัตโนมัติเมื่อรถมีผู้ขับและอยู่ในความมืด/ฝน จุดติดตั้งค่าเริ่มต้นใช้กับรถเดโม
- เสียงนก/แมลงกลางคืนแบบสังเคราะห์ และ NPC หยุดเดินตามตารางเวลากลางคืน
- HUD แสดงเวลาและอากาศ บันทึก/โหลดสภาพอากาศทั้ง 4 แบบ รองรับเซฟ Clear/Rain เดิม

## ปุ่ม

| ปุ่ม | การทำงาน |
| --- | --- |
| T | ข้ามเวลา 3 ชั่วโมง |
| Y | หยุด/เดินนาฬิกา (อากาศยังเปลี่ยนได้) |
| R | เปลี่ยนอากาศทีละแบบ |
| Esc | พักเกม รวมเวลาและการเปลี่ยนอากาศ |
| F5 / F9 | บันทึก / โหลด |
| L | ภาษาไทย / อังกฤษ |

ปรับเวลาใน Inspector ของ Sun (`DayNightCycle.Hour`) เพื่อดูช่วงเช้าประมาณ 6:00 เย็น 17:30 และกลางคืน 0:00 การโหลดเซฟคืนค่าเวลาและชนิดอากาศทันที แต่ไม่ได้คืนตำแหน่งเมฆหรือความคืบหน้าการแห้งของถนน

## การตรวจสอบ

`Scripts/Editor/EnvironmentValidation.cs` มี Play Mode smoke checks สำหรับการติดตั้งในฉากเดิม วงจรแสง นาฬิกาข้ามเที่ยงคืน ทิศฝน ไฟถนน/รถ การเปลี่ยนอากาศ ถนนเปียก การพักเกม และ save/load ทุกชนิดอากาศ ใช้ Unity batch mode กับ `-executeMethod AyutthayaSimulator.Editor.EnvironmentValidation.Run` โดยไม่ใช้ `-quit` หรือ `-nographics` ผลและภาพอยู่ใน `Logs/EnvironmentValidation` ของ Unity project

นี่คือการพัฒนาระบบบรรยากาศแนวเกมเมืองสมจริง โดยใช้ GTA 6 เป็นแนวทางด้านอารมณ์ภาพ ไม่ใช่การจำลองระบบหรือคุณภาพกราฟิกทั้งหมดของ GTA 6 โมเดลอาคาร รถ พื้นดิน และ NPC ของเดโมยังเป็นทรัพยากรเดิม
