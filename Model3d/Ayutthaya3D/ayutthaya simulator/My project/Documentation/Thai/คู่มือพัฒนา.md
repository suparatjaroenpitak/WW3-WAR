# AYUTTHAYA SIMULATOR — คู่มือพัฒนา

นี่คือฐานระบบที่เล่นได้ในขอบเขตเดโม ไม่ใช่เกมทั้งจังหวัดที่เสร็จแล้ว ห้ามอ้างว่าระบบผ่านการทดสอบถ้ายังไม่ได้เปิด Play Mode

## 1. โปรเจกต์ที่ตรวจแล้ว

- โปรเจกต์ Unity: `Model3d/Ayutthaya3D/ayutthaya simulator/My project`
- เวอร์ชันใน `ProjectVersion.txt`: **6000.6.5f1**
- พipeline ที่ใช้งาน: URP (`Assets/Settings/PC_RPAsset.asset`)
- อินพุตเป็น Input System เท่านั้น ห้ามใช้ `UnityEngine.Input` แบบเก่า
- ไม่ได้แก้ไฟล์เกม WW3 WAR

## 2. วิธีเปิดเดโม

1. เปิดโปรเจกต์ด้วย Unity 6000.6.5f1
2. เปิดซีน `Assets/_AyutthayaSimulator/Scenes/AyutthayaDemo.unity`
3. กด Play ถ้ายังไม่มี `WorldRoot` สคริปต์ `DemoSceneBootstrap` จะสร้างโลกให้
4. ถ้าต้องการ bake ใน Editor: เมนู **Tools > Ayutthaya Simulator > Generate Demo Scene**

ถ้า Console มี error จากแพ็กเกจ `com.unity.dt.app-ui` นั่นเป็นของเทมเพลต ไม่ใช่ของซิมูเลเตอร์นี้ Play Mode จะเล่นไม่ได้จนกว่าโปรเจกต์จะคอมไพล์ผ่าน อย่ารายงานว่าเดโมเล่นได้ในสภาพนั้น

## 4. ข้อมูลในเดโมไทล์

- จุดกำเนิด: วัดพระศรีสรรเพชญ์ จาก Nominatim/OSM รหัส `37447698` พิกัด 14.3559133 N, 100.5585079 E
- แปลง WGS84 เป็น UTM Zone 47N (EPSG:32647) แล้วเลื่อน +250 เมตร เพื่อให้ไทล์ 0 ครอบคลุม 0–500 เมตร
- อาคาร 132 รูป ถนน 81 ช่วง แหล่งน้ำ 8 รายการ จาก OSM API
- สัญญาอนุญาต ODbL 1.0 ต้องแสดงข้อความ © OpenStreetMap contributors
- รายละเอียดแหล่งข้อมูล: `Model3d/Ayutthaya3D/data/metadata/demo_tile_500m.metadata.json`
- พื้นดินเป็น **Placeholder แบน** ไม่ได้ดาวน์โหลด DEM และไม่ใช่ความสูงจริง
- ความสูงอาคารเป็นค่าประมาณ เว้นแต่ `heightSource` เป็น `osm_height_tag`
- ความกว้างถนนเป็นค่าประมาณ เว้นแต่ `widthSource` เป็น `osm_width_tag`
- ประตู รถสีแดง NPC และไฟถนนเป็นการวางเชิงกระบวน ไม่ใช่ตำแหน่งที่สำรวจ
- แท็ก historic เป็นเมตาดาตาเท่านั้น ยังไม่สร้างสถาปัตยกรรมวัด reconstructed

## 5. การผูกสคริปต์กับโมเดล

ชื่อไฟล์หรือชื่อวัตถุอย่างเดียวใช้ไม่ได้

1. เลือก root ของโมเดลที่นำเข้า
2. รัน **Tools > Ayutthaya Simulator > Validate Asset**
3. ถ้าไม่มี Mesh ให้หยุด อย่าใส่สคริปต์เกม
4. กำหนดชนิดด้วย `ModelImportProfile` เมื่อรู้ชนิดจริง
5. ค่อยรัน **Auto Bind Components**
6. **Generate Colliders** ใส่ MeshCollider แบบไม่ convex และตั้งวัตถุนั้นเป็น static
7. **Setup LOD** ใช้ renderer ที่มีอยู่แล้ว ไม่สร้าง mesh ใหม่จากชื่อ
8. **Generate Prefab** จะไม่บันทึกถ้า validation ไม่ผ่าน

ตัวอย่าง hierarchy:

```
BuildingRoot
  LOD0     มี Mesh, Material, MeshCollider
  LOD1     renderer ที่ละเอียดน้อยกว่า ถ้ามี
  Door     mesh แยก, DoorController, ยังไม่ถือว่า pivot ถูกต้องจนกว่าจะตรวจ
```

## 6. เซฟ ภารกิจ และ streaming

- ไฟล์เซฟอยู่ที่ `Application.persistentDataPath/ayutthaya-simulator-save.json` เวอร์ชัน 1
- การโหลดคืนตำแหน่ง ภาษา เวลา อากาศ และภารกิจที่ทำแล้ว แต่ไม่พาผู้เล่นกลับเข้าไปในรถ
- ภารกิจเดโม: เดินไปจุดสีเหลือง พูดกับ `guide_npc` และขึ้น `demo_vehicle`
- ไทล์ข้างเคียงยังไม่ถูกสร้าง `WorldStreamer` จะระบุว่าไม่มีข้อมูล ห้ามสร้างภูมิประเทศปลอม
- ไฟล์ GLB ไฟล์เดียวไม่ใช่ระบบ world streaming

## 7. สิ่งที่ยังไม่ทำ

- ยังไม่ได้วัดผล Play Mode การขับรถ NavMesh และเฟรมเรต
- ยังไม่ได้ build ไฟล์ Windows
- Blender MCP ไม่ได้เชื่อม จึงยังไม่มีไฟล์ BLEND/GLB จากขั้นตอนนี้
- ยังไม่ได้ติดตั้ง Addressables และ Unity Localization ภาษาไทย/อังกฤษใช้ `LocalizationCatalog`
- ยังไม่มีภายในอาคารจริง และยังไม่ขยายทั้งจังหวัด
